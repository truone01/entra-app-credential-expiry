How to get an alert before an Entra ID app secret or certificate expires

Microsoft Entra ID (Azure AD) doesn't send a notification when a client secret or certificate on an app registration is about to expire. Microsoft Q&A answers to this question keep saying the same thing: there isn't a built-in alert in the portal. Expiry is still the most common reason an integration "suddenly" stops working. These are the options, cheapest first.

1. Check by hand, now

In the portal, open App registrations > All applications. The list has a column that flags certificates and secrets that are expired or expiring soon. That covers app registrations only. SAML signing certificates live on Enterprise applications. To see both in one list, run the free PowerShell report:

Install-Module Microsoft.Graph -Scope CurrentUser
./Get-EntraCredentialExpiry.ps1 -Days 60 -IncludeOwners

2. The Entra recommendation

Entra has a recommendation called Renew expiring application credentials. It is a preview and needs Microsoft Entra Workload ID Premium licences, so most small tenants don't have it.

3. A scheduled script

Run a Graph query daily (Azure Automation runbook, Azure Function or a scheduled task) and email the result. Use app-only authentication with a certificate and grant Application.Read.All. The catch: the automation's own certificate expires too, and someone has to own the job.

4. A Logic App or Power Automate flow

An HTTP action calls GET https://graph.microsoft.com/v1.0/applications?$select=displayName,appId,passwordCredentials,keyCredentials, a filter keeps entries whose endDateTime is within N days, and a mail action sends them. Remember to follow @odata.nextLink for paging, and query /servicePrincipals as well for SAML certificates.

5. A hosted monitor

Paid monitoring tools (for example Site24x7's Entra ID monitoring, or Token Watch on the Microsoft Marketplace) do the scheduling and alerting for you. This makes most sense when you look after several tenants, where one script per tenant becomes a maintenance job of its own.

Look after many tenants? SecretLapse (in development) will check app secrets and certificates in every tenant you manage, every day, and email you 30, 14, 7 and 1 days before one expires. Read-only, $29/month for up to 25 tenants. It isn't available yet: price and waitlist.
