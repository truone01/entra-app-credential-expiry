Entra app credential expiry · Free script on GitHub

Find expiring client secrets and certificates in Entra ID with PowerShell

This lists every client secret and certificate in a tenant that is expired or expires within N days. It covers app registrations and enterprise apps (service principals), with owners and a CSV export.

Quick version

Connect-MgGraph -Scopes Application.Read.All
$limit = (Get-Date).AddDays(30)
Get-MgApplication -All -Property displayName,appId,passwordCredentials,keyCredentials |
  ForEach-Object {
    $app = $_
    @($app.PasswordCredentials) + @($app.KeyCredentials) | Where-Object { $_ -and $_.EndDateTime -lt $limit } |
      Select-Object @{n="App";e={$app.DisplayName}}, DisplayName, EndDateTime
  }

This misses service principal credentials (SAML signing certificates) and owners.

Full version

The free Get-EntraCredentialExpiry.ps1 (MIT) checks both object types, sorts by days left, adds owners and writes a CSV:

./Get-EntraCredentialExpiry.ps1 -Days 90 -IncludeOwners -CsvPath ./expiring.csv
./Get-EntraCredentialExpiry.ps1 -All -TenantId contoso.onmicrosoft.com

Permissions

Application.Read.All (delegated) is enough. Graph never returns secret values, only metadata (display name, key id, start and end date), so a report like this can't leak a secret.

Gotchas

  • Use -All on the Get cmdlets, or you only get the first page.
  • Service principals have their own keyCredentials, separate from the app registration. SAML apps keep their signing certificate there.
  • Dates come back in UTC.
